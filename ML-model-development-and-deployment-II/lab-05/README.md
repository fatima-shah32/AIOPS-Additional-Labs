# Lab 05: Real-time Anomaly Detection in Cloud Infrastructure

## Objective

Monitor cloud infrastructure and identify anomalies in real time using machine learning.

## Tools Used

- Python
- Scikit-learn
- Isolation Forest
- Pandas
- Matplotlib
- Prometheus Client
- Kubernetes
- Helm
- Prometheus

## Tasks Performed

1. Created simulated cloud infrastructure logs
2. Generated CPU, memory, and response time metrics
3. Scaled features using StandardScaler
4. Trained Isolation Forest anomaly detection model
5. Detected abnormal infrastructure behavior
6. Exported Prometheus-compatible metrics
7. Created Prometheus alert rules
8. Generated reports and charts
