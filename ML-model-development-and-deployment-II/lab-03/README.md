# Lab 03: ML-driven Continuous Integration in DevOps

## Objective

Enhance CI pipelines with predictive machine learning models to anticipate potential build failures.

## Tools Used

- Jenkins
- Python
- Pandas
- Scikit-learn
- Matplotlib
- TensorFlow
- Joblib

## Tasks Performed

1. Created simulated Jenkins build history dataset
2. Trained Random Forest model
3. Predicted build success or failure
4. Generated confusion matrix
5. Saved ML model
6. Created Jenkins prediction script
7. Created Jenkinsfile pipeline
8. Generated final report
