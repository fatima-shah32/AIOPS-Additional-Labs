# Lab 04: SysOps System Health Prediction with Time Series Analysis

## Objective

Use time series forecasting to predict future system downtimes or disruptions.

## Tools Used

- Python
- Pandas
- NumPy
- Prophet
- Matplotlib
- Scikit-learn

## Tasks Performed

1. Simulated hourly system health logs
2. Created uptime and downtime status data
3. Converted hourly logs into daily downtime percentage
4. Trained a Prophet forecasting model
5. Predicted downtime for the next 30 days
6. Generated forecast plots
7. Created final report
