# Lab 08

## Objective

Automate security vulnerability scanning using Machine Learning.

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Requests

## Machine Learning Model

Random Forest Regressor

## Features

- Vulnerability Type
- Vulnerability Score

## Outputs

- Vulnerability dataset
- Predicted severity
- Mean Squared Error
- Final report

## Conclusion

Successfully trained a Random Forest model to predict vulnerability severity and automate security scan prioritization in a DevSecOps pipeline.
