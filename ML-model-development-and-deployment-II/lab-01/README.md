# Lab 01: Advanced Cyber Threat Detection with Open-source ML Frameworks

## Objective

Implement and optimize machine learning models for cyber threat detection using open-source ML frameworks.

## Tools Used

- Python
- Pandas
- Scikit-learn
- TensorFlow
- Matplotlib
- NumPy

## Dataset

KDD Cup 1999 10 percent dataset sample.

## Tasks Performed

1. Loaded KDD Cup 1999 network traffic dataset
2. Encoded categorical features
3. Converted labels into binary classification
4. Scaled numerical features
5. Split dataset into training and testing sets
6. Trained Random Forest model
7. Trained TensorFlow neural network
8. Evaluated both models
9. Saved reports, model, plots, and comparison results

##Conclusion
