# Lab 9: Automated Incident Reporting in SysOps

## Objective
Automate incident log extraction and categorization using NLP.

## Features
- Incident log parsing
- Server extraction
- Issue extraction
- Category classification (Security, Performance, System)
- Visualization using Matplotlib

## Run

```bash
source venv/bin/activate
python3 incident_reporting.py
```

## Output Files
- incident_report.csv
- incident_category_distribution.png
