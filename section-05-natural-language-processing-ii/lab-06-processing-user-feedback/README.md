# Lab 6: Processing User Feedback in SysOps

## Objective

Perform sentiment analysis on user feedback using TextBlob and visualize feedback sentiments using Matplotlib.

---

# Technologies Used

- Python
- Pandas
- TextBlob
- Matplotlib

---

# Features

- User feedback sentiment analysis
- Sentiment polarity detection
- Subjectivity analysis
- CSV export
- Data visualization

---

# Run Project

```bash
source venv/bin/activate
python3 user_feedback_sentiment.py
```

---

# Output Files

- feedback_sentiment_results.csv
- sentiment_polarity_barplot.png
- polarity_vs_subjectivity_scatter.png

---

# Conclusion

This lab demonstrates how SysOps teams can analyze user feedback using NLP sentiment analysis techniques with TextBlob.
