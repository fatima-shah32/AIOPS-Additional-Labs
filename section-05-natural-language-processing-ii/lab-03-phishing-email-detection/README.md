# Lab 3: Phishing Email Detection

## Objective
Build a machine learning model to detect phishing emails using NLP and TF-IDF.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Steps
1. Create dataset (phishing + legitimate emails)
2. Preprocess text (lowercasing)
3. Apply TF-IDF vectorization
4. Train Logistic Regression model
5. Evaluate model using accuracy and confusion matrix

## How to Run
```bash
pip install -r requirements.txt
python3 phishing_detection.py
