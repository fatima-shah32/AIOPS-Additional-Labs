# Lab 5: Automating Requirement Analysis in DevOps

## Objective
Use NLP + Machine Learning to classify DevOps user stories automatically.

---

## Tools Used
- Python
- spaCy
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn

---

## Steps Performed

### Step 1: Dataset Creation
Created sample user stories with categories.

### Step 2: NLP Processing
Used spaCy for:
- Tokenization
- POS tagging

### Step 3: Feature Extraction
Used TF-IDF vectorization.

### Step 4: Model Training
Trained Logistic Regression model.

### Step 5: Evaluation
Used:
- Accuracy score
- Classification report
- Confusion matrix

---

```bash
pip install -r requirements.txt
python3 main.py
