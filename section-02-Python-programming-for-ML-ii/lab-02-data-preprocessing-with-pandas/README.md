# Lab 02 - Data Preprocessing with Pandas

## Objective

Learn how to:

- Load datasets with Pandas
- Handle missing values
- Normalize numerical data
- Split data into training and testing sets

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Dataset

Iris Dataset

## Tasks Performed

1. Loaded CSV dataset
2. Simulated missing values
3. Replaced missing values with column mean
4. Normalized features using MinMaxScaler
5. Split dataset into training and testing sets

## Output

Training data shape: (120, 4)

Testing data shape: (30, 4)

## Conclusion

Successfully performed basic data preprocessing required before building machine learning models.
