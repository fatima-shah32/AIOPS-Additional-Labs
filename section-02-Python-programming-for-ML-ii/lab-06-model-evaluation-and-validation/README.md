# Lab 06 - Model Evaluation and Validation

## Objective

Learn how to evaluate and validate machine learning models using Python.

## Tools Used

- Python
- NumPy
- Scikit-learn

## Concepts Covered

- Synthetic regression dataset
- Train-validation split
- Linear Regression model
- K-Fold Cross Validation
- Mean Squared Error
- Model evaluation

## Steps Performed

1. Created a synthetic regression dataset.
2. Split data into training and validation sets.
3. Implemented 5-fold cross-validation.
4. Trained a Linear Regression model.
5. Evaluated model performance using Mean Squared Error.
