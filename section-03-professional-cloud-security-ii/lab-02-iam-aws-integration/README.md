# Lab 2: Integrating IAM with AWS Services

## Objective
To simulate IAM integration with AWS services such as S3 and Lambda using local files and scripts.

## Services Covered
- Amazon S3
- AWS Lambda

## Steps Performed
1. Created IAM policy for S3 access
2. Created IAM policy for Lambda access
3. Simulated IAM role behavior using bash scripts
4. Verified IAM permission logic locally

## Note
This lab is fully simulated and does not require actual AWS cloud access.

## Conclusion
IAM policies help control secure cross-service access between AWS services like S3 and Lambda.
