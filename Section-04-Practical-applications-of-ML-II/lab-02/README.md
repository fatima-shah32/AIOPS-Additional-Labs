# Lab 02: Cloud Data Encryption with TensorFlow

## Objective

Design and implement a basic TensorFlow neural network to simulate cloud data encryption and decryption.

## Tools Used

- Python
- TensorFlow
- NumPy
- Pandas
- Matplotlib

## Concept

This lab uses a simple neural network to learn a binary transformation.  
The plaintext is converted into binary, encrypted using bit inversion, and the model learns to predict the encrypted binary output.

> Note: This is only a learning simulation. It is not real production-grade encryption.

## Tasks Performed

1. Created virtual environment
2. Installed TensorFlow and required libraries
3. Converted text into binary format
4. Created simple encrypted binary data
5. Built a neural network model
6. Trained the model to learn encryption mapping
7. Predicted encrypted output
8. Converted output back to readable text
9. Saved model, plots, CSV results, and report
