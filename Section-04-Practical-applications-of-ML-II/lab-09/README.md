# Lab 09 – Automating Security Patch Testing with ML

## Objective

Train a Linear Regression model to predict the impact of security patches before deployment.

## Tools

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Files

```text
patch_impact_prediction.py
README.md
patch_prediction.png
report.txt
```

## Workflow

1. Simulated historical security patch dataset.
2. Encoded categorical variables.
3. Trained a Linear Regression model.
4. Evaluated the model using:
   - Mean Squared Error
   - R² Score
5. Predicted the impact of a future security patch.
6. Generated a visualization and saved a report.

## Conclusion

Machine learning can assist system administrators in estimating the impact of security patches before deployment, helping reduce downtime and improve patch management decisions.
